# Q4: Josephus Problem

This program solves the Josephus Problem using three approaches:
1. 2D Array
2. Circular Singly Linked List
3. Circular Doubly Linked List

Select the approach from the menu and input the required parameters.

## Usage
- Compile with: `gcc main.c -o josephus`
- Run: `./josephus`
- Follow the menu prompts.
